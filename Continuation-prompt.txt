Important Reminders

1. Follow Java code line-by-line - The Java MigLayout v11 source is our source of truth
2. Empty arrays are not null in Pascal - Check Length(array) > 0 instead of array <> nil
3. Test-Driven Development - We've found many bugs by creating tests first
4. Memory management - Use "Clone-on-Set" strategy for BoundSize/UnitValue to avoid leaks
5. When using generics, you need to define specialized types before you can use them in
   method declarations.
6. Unit tests can be run as follows: (cd unittests && fpc -dX11 -dAggCanvas @extrafpc.cfg fpgui_unittests_console.lpr && ./fpgui_unittests_console --all --format=plain 2>&1 | tail -10)
7. We are mainly testing with the X11+AggCanvas backed, but occationally test with X11
   (AggCanvas disabled)
8. We have experienced a lot of bugs, and then discovered it's because only stubs were
   implemented in our mig porting code. So maybe it's vital that we go through all
   src/corelib/fpg_mig*.pas units looking for stub implementations, or code with TODO
   markers, and complete them - using the java code as reference.
9. Java mig code (as reference) can be found in: prototypes/miglayout/mig-java-latest/core
   & prototypes/miglayout/mig-java-latest/swing
