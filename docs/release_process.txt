Release process
===============

1. Create new release branch off 'develop':
    git checkout -b release-1.x develop

2. Bump version numbers

	docview/src/docview.rc
	project.xml
	extras/lazarus_ide/<platform>/fpgui_toolkit.lpk
	docs/manifest.xml

3. Update the CHANGELOG.txt

4. Run localization script to update all *.po files

5. Switch to 'develop' branch

6. Bump version numbers - same files as step 2.

7. Push both release and develop branches

8. Build new documentation
     [ ] INF
     [ ] HTML for website

9. Build new DocView

10. Archive Docview and INF and release to SourceForge (Github?)

11. Archive HTML and release to SourceForge.

12. Push HTML API docs to website.
    - Use rsync script in fpgui_website repository.

13. Make sure SourceForge.net shows the new version src download
    archive as the default download.



Release notification
====================

1. Update website with new release and changelog

2. Post message to FPC Users mailing list

3. Post message to Lazarus mailing list

4. Post message to Lazarus Forum (3rd party)

5. Update Wikipedia (English and Afrikaans)

6. Update FPC's wiki about fpGUI

7. Post message to fpGUI newsgroup
