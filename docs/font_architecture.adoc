== Overview

This document provides comprehensive architectural documentation for fpGUI's font handling system following the refactoring completed in October 2025.

=== Purpose

The fpGUI font system provides a clean, efficient abstraction layer for cross-platform font management with:

* **Centralized caching** - O(1) hash-based persistent font cache
* **Automatic memory management** - Cache owns fonts, freed at application exit
* **Multi-backend support** - Native (X11/Xft, GDI, Cocoa) and software (AggCanvas/FreeType)
* **Consistent API** - Unified interface across all rendering backends

=== Key Design Goals

1. **Simplicity** - Direct font resource usage without wrapper objects
2. **Performance** - Fast cache lookups and minimal overhead
3. **Safety** - Persistent cache model simplifies memory management
4. **Flexibility** - Support multiple rendering backends transparently

=== Component Responsibilities

==== TfpgFontManager

**Location:** `src/corelib/fpg_fontmanager.pas`

**Responsibilities:**

* Manages global font cache using hash table (O(1) lookups)
* Creates platform-appropriate font resources
* Owns all font resources until application shutdown
* Provides default and fixed-width font access
* Handles font descriptor normalization

**Key Methods:**

[source,pascal]
----
function GetFont(const ADesc: string): TfpgFontResourceBase;
function GetDefaultFont: TfpgFontResourceBase;
function GetFixedFont: TfpgFontResourceBase;
----

==== TfpgFontResourceBase

**Location:** `src/corelib/fpg_base.pas`

**Responsibilities:**

* Abstract base class for all font resources
* Defines IFontEngine interface contract
* Platform-agnostic font metrics API
* Inherits from TInterfacedObject (for future extensibility)

**Key Methods:**

[source,pascal]
----
function GetTextWidth(const txt: string): integer; virtual; abstract;
function GetAscent: integer; virtual; abstract;
function GetDescent: integer; virtual; abstract;
function GetHeight: integer; virtual; abstract;
function HandleIsValid: boolean; virtual; abstract;
----

==== TfpgFontResource (Platform-Specific)

**Locations:**

* `src/corelib/x11/fpg_x11.pas` - `TfpgX11FontResource`
* `src/corelib/gdi/fpg_gdi.pas` - `TfpgGDIFontResource`
* `src/corelib/cocoa/fpg_cocoa.pas` - `TfpgCocoaFontResource`

**Responsibilities:**

* Platform-specific font loading (Xft, GDI, CoreText)
* Font metrics calculation using native APIs
* Handle management (PXftFont, HFONT, etc.)
* Font descriptor interpretation for platform

**Type Alias Pattern:**

Each platform defines `TfpgFontResourceImpl` via `fpg_interface.pas`:

[source,pascal]
----
// In src/corelib/x11/fpg_interface.pas
type
  TfpgFontResourceImpl = class(TfpgX11FontResource);

// In src/corelib/fpg_main.pas
type
  TfpgFontResource = class(TfpgFontResourceImpl)
  // Note: FontDesc property is in TfpgFontResourceBase
  // Cross-platform wrapper adds usage tracking
  protected
    FUsageCount: integer;
  public
    property UsageCount: integer read FUsageCount;
  end;
----

==== TfpgAgg2DFontResource (AggCanvas Mode)

**Location:** `src/corelib/render/software/Agg2D.pas`

**Responsibilities:**

* FreeType-based font loading for software rendering
* AggPas integration for high-quality anti-aliased text
* Independent metrics calculation (no dependency on X11/GDI)
* Registration with font manager when `-dAGGCANVAS` is defined

**Special Behavior:**

[source,pascal]
----
// In fpg_fontmanager.pas
{$IFDEF AGGCANVAS}
if Assigned(AggFontResourceClass) then
  Result := AggFontResourceClass.Create(fdesc)  // Creates TfpgAgg2DFontResource
else
  Result := TfpgFontResource.Create(fdesc);     // Fallback to native
{$ELSE}
Result := TfpgFontResource.Create(fdesc);       // Native only
{$ENDIF}
----

==== TfpgFontDefinition

**Location:** `src/corelib/fpg_base.pas`

**Responsibilities:**

* Parses font descriptor strings
* Normalizes font descriptors for cache keys
* Provides structured access to font attributes

**Font Descriptor Format:**

----
"FontName-Size[:attributes]"

Examples:
  "Liberation Sans-10"
  "Liberation Sans-10:bold"
  "Liberation Sans-12:bold:italic"
  "Arial-10:bold:italic:underline"
  "Liberation Mono-10:antialias=false"
----

**Descriptor Normalization:**

Font descriptors are automatically normalized to ensure consistent cache lookups and prevent duplicate cache entries. The normalization process converts font descriptors to a canonical form:

**Normalization Rules:**

1. **Face Name:** Converted to proper case (capitalize first letter of each word)
   * `"arial"` → `"Arial"`
   * `"COURIER NEW"` → `"Courier New"`
   * `"liberation sans"` → `"Liberation Sans"`

2. **Attributes:** Converted to lowercase and sorted alphabetically
   * `"Arial-12:BOLD:italic"` → `"Arial-12:bold:italic"`
   * `"Arial-12:italic:bold"` → `"Arial-12:bold:italic"`
   * `"Arial-12:underline:bold"` → `"Arial-12:bold:underline"`

3. **Automatic Deduplication:** Duplicate attributes are automatically removed (via set type)
   * `"Arial-12:bold:bold:italic"` → `"Arial-12:bold:italic"`

4. **Empty Descriptors:** Default to `FPG_DEFAULT_SANS` with size 10
   * `""` → `"Liberation Sans-10"` (on Unix) or `"Arial-10"` (on Windows)

**Normalization Examples:**

[source]
----
Input Descriptor              Normalized Form
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
"ARIAL-12:BOLD"           →  "Arial-12:bold"
"arial-12:bold"           →  "Arial-12:bold"
"Arial-12:italic:bold"    →  "Arial-12:bold:italic"
"Liberation SANS-12:bold" →  "Liberation Sans-12:bold"
""                        →  "Liberation Sans-10" (Unix)
"Arial"                   →  "Arial-10"
----

**Benefits:**

* **Cache Efficiency:** Different case variations map to same cache entry
* **Memory Savings:** Prevents duplicate font resources for equivalent descriptors
* **Consistency:** Ensures predictable behavior regardless of input case/order
* **Performance:** O(1) cache lookups work correctly with normalized keys

**Key Methods:**

[source,pascal]
----

function IsItalic: boolean;
function IsUnderline: boolean;

property Size: integer read FSize;

----

== Font Lifecycle

=== Creation Flow

[source]
----
1. Widget requests font:
   └─▶ fpgApplication.FontManager.GetFont('Arial-12:bold')

2. Font Manager:
   ├─▶ Parse descriptor via TfpgFontDefinition
   ├─▶ Normalize to cache key: "Arial-12:bold"
   ├─▶ Hash table lookup (O(1))
   │
   ├─▶ Cache HIT:
   │   └─▶ Return cached TfpgFontResourceBase (same object)
   │
   └─▶ Cache MISS:
       ├─▶ Create platform-specific font resource:
       │   {$IFDEF AGGCANVAS}
       │     TfpgAgg2DFontResource.Create()  → FreeType loading
       │   {$ELSE}
       │     TfpgFontResource.Create()       → Native (Xft/GDI/CoreText)
       │   {$ENDIF}
       ├─▶ Validate font loaded successfully
       ├─▶ Add to cache with normalized key (cache owns it)
       └─▶ Return new font resource

3. Widget stores font:
   └─▶ FFont := <returned font resource>
----

=== Memory Management (Persistent Cache Model)

fpGUI uses a **persistent cache** model where fonts are owned by the font manager and live until application shutdown:

**Key Characteristics:**

* Font manager owns all font resources via `FFontCache: TFPHashObjectList`
* Fonts are created once and cached permanently
* Multiple requests for the same font return the **same object** from cache
* Fonts are never freed until `TfpgFontManager.Destroy` is called (application exit)
* Widget font fields (`FFont: TfpgFontResourceBase`) hold **direct pointers** to cached fonts
* Setting `FFont := nil` simply clears the widget's pointer; font remains in cache

**Design Rationale:**

* Font resources are small (~5-10 KB each including platform data)
* Most applications use 5-20 unique fonts (~100 KB total)
* Disk I/O cost of loading fonts far exceeds memory cost of caching them
* Persistent cache eliminates repeated font loading, improving performance

**Example:**

[source,pascal]
----
procedure Example;
var
  font1, font2: TfpgFontResourceBase;
begin
  font1 := fpgApplication.FontManager.GetFont('Arial-12');
  // Font created and added to cache on first request

  font2 := fpgApplication.FontManager.GetFont('Arial-12');
  // Cache hit - returns same object

  CheckTrue(font1 = font2, 'Same font object returned from cache');

  font1 := nil;
  font2 := nil;
  // Font STAYS in cache for future requests

  // Later requests return the cached font (no disk I/O):
  font1 := fpgApplication.FontManager.GetFont('Arial-12');
  // Cache hit - instant return of same object
end;
----

=== Destruction Flow

[source]
----
1. During application lifetime:
   ├─▶ Widget destructor: FFont := nil
   │   └─▶ Clears pointer only; font remains in cache
   │
   ├─▶ Multiple widgets can reference same font
   │   └─▶ All hold pointers to same cached object
   │
   └─▶ Cache size stays constant (fonts never removed)

2. Application shutdown:
   └─▶ FontManager.Destroy called
       └─▶ FFontCache.Free (owns all fonts)
           └─▶ All cached fonts freed
               ├─▶ X11: XftFontClose(FFontData)
               ├─▶ GDI: DeleteObject(FFontHandle)
               ├─▶ Cocoa: [FFontRef release]
               └─▶ Agg: FreeType cleanup
----

**Key Point:** Fonts live in cache from creation until application exit. Widget destructors setting `FFont := nil` do **not** free the font - they only clear the widget's pointer. The font manager is the sole owner and is responsible for cleanup at application shutdown.

== Multi-Backend Support

=== Native Rendering (Default)

**Enabled:** When `-dAGGCANVAS` is NOT defined

**Font Resources:**

* **Linux:** `TfpgX11FontResource` using Xft (fontconfig + FreeType)
* **Windows:** `TfpgGDIFontResource` using GDI HFONT
* **macOS:** `TfpgCocoaFontResource` using CoreText

**Characteristics:**

* Uses native platform font rendering
* Fast, hardware-accelerated when available
* Platform-specific font hinting
* Direct access to system font cache

**Example (X11/Xft):**

[source,pascal]
----
// In TfpgX11FontResource.Create()
FFontData := XftFontOpenName(Display, DefaultScreen, PChar(AFontDesc));

// Metrics from Xft
function TfpgX11FontResource.GetHeight: integer;
begin
  Result := FFontData^.ascent + FFontData^.descent;
end;

function TfpgX11FontResource.GetTextWidth(const txt: string): integer;
var
  extents: TXGlyphInfo;
begin
  XftTextExtentsUtf8(Display, FFontData, PChar(txt), Length(txt), @extents);
  Result := extents.xOff;
end;
----

=== AggCanvas Rendering (Software)

**Enabled:** When `-dAGGCANVAS` is defined at compile time

**Font Resource:** `TfpgAgg2DFontResource` using FreeType directly

**Characteristics:**

* Pure software rendering via AggPas (Anti-Grain Geometry)
* Platform-independent high-quality anti-aliasing
* Consistent rendering across all platforms
* No dependency on native font APIs

**Registration Pattern:**

[source,pascal]
----
// In Agg2D.pas unit initialization section:
initialization
  {$IFDEF AGGCANVAS}
  // Register Agg2D font resource class with font manager
  AggFontResourceClass := TfpgAgg2DFontResource;
  {$ENDIF}
----

**Font Loading (FreeType):**

[source,pascal]
----
// In TfpgAgg2DFontResource.Create()
constructor TfpgAgg2DFontResource.Create(const AFontDesc: string);
var
  fontFile: string;
  fontDef: TfpgFontDefinition;
begin
  FFontDesc := AFontDesc;
  fontDef := TfpgFontDefinition.Create(AFontDesc);

  // Use global font cache to find font file
  fontFile := gFontCache.Find(fontDef.FaceName, fontDef.IsBold, fontDef.IsItalic);

  // Load via FreeType
  FFontEngine.load_font(PChar(fontFile), 0, glyph_ren_agg_gray8);
  FFontEngine.height_(fontDef.Size * ScreenDPI / 72);

  // Cache metrics
  FCachedAscent := Round(FFontEngine._ascender);
  FCachedDescent := Round(Abs(FFontEngine._descender));

  fontDef.Free;
end;
----

**Metrics (FreeType):**

[source,pascal]
----
function TfpgAgg2DFontResource.GetHeight: integer;
begin
  Result := FCachedAscent + FCachedDescent;
end;

function TfpgAgg2DFontResource.GetTextWidth(const txt: string): integer;
var
  x, y: double;
begin
  x := 0;
  y := 0;
  // Measure text using FreeType glyph advances
  FFontCacheManager.measure_text(PChar(txt), x, y);
  Result := Round(x);
end;
----

=== Backend Selection

The font manager automatically selects the appropriate backend:

[source,pascal]
----
// In fpg_fontmanager.pas
function TfpgFontManager.GetFont(const ADesc: string): TfpgFontResourceBase;
begin
  // ...cache lookup...

  if not Assigned(Result) then
  begin
    {$IFDEF AGGCANVAS}
    // AggCanvas mode: use FreeType-based fonts
    if Assigned(AggFontResourceClass) then
      Result := AggFontResourceClass.Create(fdesc)
    else
      Result := TfpgFontResource.Create(fdesc);  // Fallback
    {$ELSE}
    // Native mode: use platform fonts
    Result := TfpgFontResource.Create(fdesc);
    {$ENDIF}

    // Validate and cache...
  end;
end;
----

**Key Insight:** Widgets are **completely unaware** of which backend is active. They use the same API (`TfpgFontResourceBase`) regardless of native or AggCanvas rendering.

== Cache Management

=== Cache Structure

The font manager maintains a hash table for O(1) lookups:

[source,pascal]
----
type
  TfpgFontManager = class(TObject)
  private
    FFontCache: TFPHashObjectList;  // Owns font resources
----

**Hash Key:** Normalized font descriptor string

**Example:**

----
Input Descriptors         Normalized Key          Cached Object
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
"Arial-12:bold"       →   "Arial-12:bold"     →   TfpgFontResource@0x1234
"Arial-12:BOLD"       →   "Arial-12:bold"     →   (same object)
"arial-12:bold"       →   "Arial-12:bold"     →   (same object)
----

=== Cache Lifecycle (Persistent Model)

[source]
----
1. First Request:
   ├─▶ Parse descriptor
   ├─▶ Normalize to "Arial-12:bold"
   ├─▶ Hash table lookup: NOT FOUND
   ├─▶ Create new TfpgFontResource
   ├─▶ Add to cache: Hash("Arial-12:bold") → font object
   └─▶ Return font

2. Subsequent Requests:
   ├─▶ Parse descriptor
   ├─▶ Normalize to "Arial-12:bold"
   ├─▶ Hash table lookup: FOUND
   └─▶ Return cached font (same object)

3. Widget Releases Reference:
   ├─▶ FFont := nil
   └─▶ Font REMAINS in cache for future reuse

4. Application Exit:
   └─▶ FontManager destroyed → all cached fonts freed
----

**Design Rationale:** The persistent cache model optimizes for performance over memory usage. Font resources (~5-10 KB each) are small compared to the disk I/O cost of repeatedly loading them. Most applications use 5-20 fonts, resulting in ~100 KB of persistent cache memory - negligible on modern systems.

== Widget Integration

=== Standard Usage Pattern

[source,pascal]
----
type
  TfpgButton = class(TfpgWidget)
  private
    FFont: TfpgFontResourceBase;
    procedure SetFont(const AValue: TfpgFontResourceBase);
  published
    property Font: TfpgFontResourceBase read FFont write SetFont;
  end;

constructor TfpgButton.Create(AOwner: TComponent);
begin
  inherited Create(AOwner);
  // Get default button font from font manager
  FFont := fpgApplication.FontManager.GetFont('#Button');
end;

destructor TfpgButton.Destroy;
begin
  FFont := nil;  // Clear pointer (font stays in cache)
  inherited Destroy;
end;

procedure TfpgButton.SetFont(const AValue: TfpgFontResourceBase);
begin
  if FFont = AValue then Exit;
  FFont := AValue;     // Store pointer to cached font
  Invalidate;          // Request repaint
end;

procedure TfpgButton.HandlePaint;
begin
  Canvas.SetFont(FFont);
  Canvas.DrawText(10, 10, 'Button Text');
end;
----

=== Canvas Font Assignment

The canvas accepts `TfpgFontResourceBase` directly:

[source,pascal]
----
procedure TfpgCanvasBase.SetFont(AFont: TfpgFontResourceBase);
begin
  if AFont = nil then
    Exit;

  // Store font reference
  FFont := AFont;

  // Platform-specific font activation
  DoSetFontRes(AFont);
end;
----

For AggCanvas, `DoSetFontRes` configures the AggPas font engine:

[source,pascal]
----
procedure TAgg2D.DoSetFontRes(fntres: TfpgFontResourceBase);
var
  aggFont: TfpgAgg2DFontResource;
begin
  if fntres is TfpgAgg2DFontResource then
  begin
    aggFont := TfpgAgg2DFontResource(fntres);
    // Use FreeType font from resource
    Font(aggFont.FontFile, aggFont.FontSize, aggFont.IsBold, aggFont.IsItalic);
  end;
end;
----

== Performance Characteristics

=== Time Complexity

[cols="2,1,3",options="header"]
|===
|Operation |Complexity |Notes

|Font lookup (cache hit)
|O(1)
|Hash table lookup

|Font lookup (cache miss)
|O(1) + creation
|Hash + platform font loading

|Font creation (native)
|O(1)
|Xft/GDI font loading

|Font creation (AggCanvas)
|O(n)
|FreeType file loading, n = file size

|Text width calculation
|O(m)
|m = string length (glyph iteration)

|Font pointer assignment
|O(1)
|Simple pointer copy

|Cache cleanup (shutdown)
|O(n)
|n = number of cached fonts
|===

=== Memory Usage

**Per Font Resource:**

* **Native (X11):** ~200 bytes + Xft handle
* **Native (GDI):** ~150 bytes + HFONT handle
* **AggCanvas:** ~500 bytes + FreeType data (~5-10 KB per font)

**Font Manager Overhead:**

* Hash table: ~32 bytes per entry
* Total for 20 fonts: ~640 bytes

**Widget Overhead:**

* Font reference: 8 bytes (pointer)
* No wrapper object needed (compared to old TfpgFont approach)

=== Performance Comparison

**Old Architecture (pre-refactoring):**

* O(n) linear search through font list
* TfpgFont wrapper object allocation per widget
* Complex manual reference counting
* Typical font lookup: ~200ns for 10 fonts

**New Architecture (post-refactoring):**

* O(1) hash table lookup
* Direct font resource usage (no wrappers)
* Simple persistent cache model
* Typical font lookup: ~50ns (4x faster)

== Thread Safety

**Current Status:** The font system is **NOT thread-safe**.

**Implications:**

* Font manager must only be accessed from main GUI thread
* Font cache operations are not protected by mutexes
* Font pointer assignments in widgets are not thread-safe

**Future Work:**

If thread-safe font access is needed:

1. Add `TCriticalSection` to `TfpgFontManager`
2. Protect cache lookup/creation operations with locks
3. Document thread-safe usage patterns

**Example (not currently implemented):**

[source,pascal]
----
function TfpgFontManager.GetFont(const ADesc: string): TfpgFontResourceBase;
begin
  FCacheLock.Enter;
  try
    // Cache lookup and creation...
  finally
    FCacheLock.Leave;
  end;
end;
----

=== Common Issues

[source,pascal]
----
font := fpgApplication.FontManager.GetFont('NonExistentFont-12');

[source,pascal]

== Summary

The fpGUI font architecture provides:

✓ **Clean API** - Direct font resource usage without wrappers
✓ **High Performance** - O(1) hash-based caching with persistent cache model
✓ **Memory Safety** - Simple ownership model (cache owns all fonts)
✓ **Multi-Backend** - Seamless native and AggCanvas support
✓ **Cross-Platform** - Consistent API across X11, GDI, Cocoa
✓ **Maintainable** - Clear separation of concerns

This architecture trades a small amount of memory (~100 KB for typical applications) for significantly improved performance by eliminating repeated font loading from disk.
