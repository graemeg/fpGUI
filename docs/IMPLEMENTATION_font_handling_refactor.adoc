== Architecture Overview

=== Current Canvas Hierarchy

----
TfpgCanvasBase (abstract base in fpg_base.pas)
├── TfpgX11Canvas (platform-specific)
├── TfpgGDICanvas (platform-specific)
├── TfpgCocoaCanvas (platform-specific)
└── TAgg2D (AGG-based renderer, inherits from TfpgCanvasBase)
----

=== Compilation Model

* *Compile-time selection:* `{$IFDEF AggCanvas}` determines which canvas is used
* On Darwin (macOS): AggCanvas is enabled by default in `fpg_defines.inc:5`
* `TfpgCanvasImpl` is aliased to platform canvas (X11/GDI/Cocoa) in each `fpg_interface.pas`
* `TfpgCanvas` extends `TfpgCanvasImpl` with higher-level drawing methods
* *Runtime choice:* `DefaultCanvasClass` is set in initialization (fpg_main.pas:3221):
** If `AggCanvas` defined: uses `TAgg2D`
** Otherwise: uses `TfpgCanvas` (platform-specific)
* Widgets create canvas via: `DefaultCanvasClass.Create(self)` (fpg_widget.pas:471)

=== The Problem

When `AggCanvas` is enabled:

* Widgets get `TAgg2D` instances for rendering
* But `TfpgFontBase.TextWidth/Ascent/Descent/Height` still call `FFontRes` (platform native)
* This creates the "two-engine problem": metrics from native, rendering from FreeType
* Current hack (commit 0dc72998) bypasses this by casting `fpgApplication.MainForm.Canvas` to `TAgg2D`

=== The Solution

Introduce `IFontEngine` interface and make fonts canvas-aware:

* Each canvas type configures fonts with the appropriate engine
* `TAgg2D` configures fonts to use `TAgg2DFontEngine` (FreeType metrics)
* Platform canvases configure fonts to use platform font resources (native metrics)
* Fonts delegate all metric calls to their assigned `IFontEngine`

constructor TfpgFontDefinition.Create(const AFontDesc: string);
begin

  FFontDesc := AFontDesc;

end;

procedure TfpgFontDefinition.ParseFontDesc;
var
  cp: integer;
  c: TfpgChar;
  token: string;
  prop: string;
  propval: string;
begin
  // TODO: Implement font descriptor parsing
  // This should parse descriptors like: "Liberation Sans-10:bold:italic"
  // For now, basic implementation:

  cp := 1;
  FFaceName := '';
  FSize := 10;  // default
  FAttributes := [];
  FAntiAliased := True;  // default

  // Extract face name (everything before '-' or ':')
  while (cp <= Length(FFontDesc)) and (FFontDesc[cp] <> '-') and (FFontDesc[cp] <> ':') do
  begin
    FFaceName := FFaceName + FFontDesc[cp];
    Inc(cp);
  end;

  // Extract size (number after '-')
  if (cp <= Length(FFontDesc)) and (FFontDesc[cp] = '-') then
  begin
    Inc(cp);
    token := '';
    while (cp <= Length(FFontDesc)) and (FFontDesc[cp] >= '0') and (FFontDesc[cp] <= '9') do
    begin
      token := token + FFontDesc[cp];
      Inc(cp);
    end;
    if token <> '' then
      FSize := StrToIntDef(token, 10);
  end;

  // Parse attributes (after ':')
  while cp <= Length(FFontDesc) do
  begin
    if FFontDesc[cp] = ':' then
    begin
      Inc(cp);
      prop := '';
      propval := '';

      // Extract property name
      while (cp <= Length(FFontDesc)) and (FFontDesc[cp] <> '=') and (FFontDesc[cp] <> ':') do
      begin
        prop := prop + LowerCase(FFontDesc[cp]);
        Inc(cp);
      end;

      // Extract property value if present
      if (cp <= Length(FFontDesc)) and (FFontDesc[cp] = '=') then
      begin
        Inc(cp);
        while (cp <= Length(FFontDesc)) and (FFontDesc[cp] <> ':') do
        begin
          propval := propval + LowerCase(FFontDesc[cp]);
          Inc(cp);
        end;
      end;

      // Apply property
      if prop = 'bold' then
        FAttributes := FAttributes + [fpgFontBold]
      else if prop = 'italic' then
        FAttributes := FAttributes + [fpgFontItalic]
      else if prop = 'underline' then
        FAttributes := FAttributes + [fpgFontUnderline]
      else if prop = 'antialias' then
        FAntiAliased := (propval <> 'false');
    end
    else
      Inc(cp);
  end;
end;

constructor TAgg2DFontEngine.Create(AAgg2D: TAgg2D; AFontDef: TfpgFontDefinition);

  inherited Create;
  FAgg2DRef := AAgg2D;  // Weak reference - caller owns this
  FFontDefinition := AFontDef;

== Troubleshooting

=== Common Issues

==== Issue: Fonts return zero metrics

*Symptoms:* `TextWidth`, `Ascent`, etc. return 0

*Possible causes:*

. Font engine not configured (FFontEngine is nil)
. Canvas didn't call ConfigureFontEngine
. Font not properly loaded in Agg2D

*Solutions:*

. Verify Canvas.SetFont was called
. Check ConfigureFontEngine implementation
. Debug with breakpoints in metric methods

==== Issue: Metrics still inconsistent with AggCanvas

*Symptoms:* Text layout doesn't match rendering

*Possible causes:*

. TAgg2D.ConfigureFontEngine not called
. Font loaded after engine created
. Wrong conditional compilation

*Solutions:*

. Verify {$IFDEF AggCanvas} is set correctly
. Check SetFont call order
. Verify TAgg2D override is being called

==== Issue: Memory leaks

*Symptoms:* Heap trace shows leaks

*Possible causes:*

. TfpgFontDefinition not freed
. TAgg2DFontEngine holds strong reference
. Interface reference counting issues

*Solutions:*

. Check destructor implementations
. Verify weak references in TAgg2DFontEngine
. Use interface assignment (not pointer manipulation)

==== Issue: Access violations

*Symptoms:* Crashes when accessing font metrics

*Possible causes:*

. TAgg2DFontEngine accessing freed TAgg2D
. Nil font definition
. Invalid font resource

*Solutions:*

. Add nil checks in all metric methods
. Verify canvas lifecycle
. Check font creation order
