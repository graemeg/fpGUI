== Executive Summary

This document provides a comprehensive redesign proposal for the fpGUI font handling system based on detailed analysis of the current implementation. The analysis reveals that while recent bug fixes (commits 9b58fb60 and others) have addressed critical memory leaks, the fundamental architecture remains overly complex with unclear ownership patterns, incomplete refactoring, and scattered responsibilities.

=== Key Findings

* **Fixed Issues**: Double reference counting and FOwnedFont memory leaks have been resolved
* **Current State**: Codebase is mid-refactoring with both old (TfpgFont → TfpgFontResource) and new (TfpgFontDefinition → IFontEngine) paths coexisting
* **Critical Issues**: No font manager abstraction, O(n) cache lookups, manual reference counting remains error-prone
* **Unnecessary Complexity**: TfpgFont wrapper adds no value, confusing dual ownership model

=== Recommended Approach

**Phased Moderate Refactoring** that:

1. Creates a dedicated `TfpgFontManager` class with O(1) hash-based caching
2. Removes the unnecessary `TfpgFont` wrapper class entirely
3. Widgets directly reference `TfpgFontResource` with interface-based automatic reference counting
4. Consolidates font descriptor parsing in `TfpgFontDefinition`
5. Completes the IFontEngine transition across all backends


* **Estimated Time**: 2-3 weeks for experienced developer
* **Risk Level**: Medium (requires touching ~30-40 widget files)
* **Benefits**: Significantly simplified architecture, better performance, clearer lifecycle management

=== 1.2 Critical Issues Identified

==== 1. TfpgFont Wrapper Adds No Value

*Location:* `src/corelib/fpg_base.pas:341-362`

The `TfpgFont` class serves only as a thin wrapper that:

* Duplicates `FFontDesc` string (already stored in `TfpgFontResource`)
* Delegates all method calls to `FFontRes` or `FFontEngine`
* Complicates lifecycle management with dual ownership model
* Forces every font user to manage wrapper objects

[source,pascal]
----
TfpgFontBase = class(TObject)
protected
  FFontDesc: string;                    // ← Duplicates FFontRes.FontDesc
  FFontRes: TfpgFontResourceBase;       // ← The actual resource
  FFontEngine: IFontEngine;             // ← NEW path
  FFontDefinition: TfpgFontDefinition;   // ← NEW path
public
  function TextWidth(const txt: TfpgString): integer;  // ← Just delegates
  function Ascent: integer;                            // ← Just delegates
  function Descent: integer;                           // ← Just delegates
----

Widgets use this confusing pattern:

[source,pascal]
----
// Widget "owns" the wrapper, but the resource is globally cached
FFont: TfpgFont;

procedure SetFont(const AValue: string);
begin
  FFont.Free;                       // Decrements ref count, maybe frees resource
  FFont := fpgGetFont('Arial-12');  // Creates new wrapper
end;
----

**Problem**: Widget thinks it "owns" the font, but it's borrowing a wrapper to a shared resource.

==== 2. No Centralized Font Manager

*Location:* `src/corelib/fpg_main.pas:315, 1566-1602`

Font management is scattered across `TfpgApplication` with no encapsulation:

[source,pascal]
----
TfpgApplication = class(TfpgApplicationImpl)
private
  FFontResList: TList;  // Just a TList, no abstraction
public
  function GetFont(const afontdesc: TfpgString): TfpgFont;
  procedure FreeFontRes(afontres: TfpgFontResource);
----

**Missing:**

* No dedicated `TfpgFontManager` class
* No hash table for O(1) lookups (currently O(n) linear search through string comparisons)
* Cache logic mixed into application singleton
* Hard to unit test or mock
* No cache statistics or debugging capabilities

==== 3. Manual Reference Counting is Error-Prone

*Location:* `src/corelib/fpg_main.pas:1990-1999`

[source,pascal]
----
function TfpgFontResource.IncRefCount: integer;
begin
  Inc(FUsageCount);
  Result := FUsageCount;
end;

function TfpgFontResource.DecRefCount: integer;
begin
  Dec(FUsageCount);
  Result := FUsageCount;
end;
----

**Issues:**

* No protection against negative counts
* No assertions to catch bugs
* Easy to forget Inc/Dec pairs
* Already caused memory leaks (fixed in commit 9b58fb60)

=== 2.2 Key Changes

1. **Remove TfpgFont** entirely - widgets use `TfpgFontResource` directly
2. **Create TfpgFontManager** - dedicated class for font management
3. **Use TInterfacedObject** - automatic reference counting via interfaces
4. **Hash-based cache** - O(1) lookup using `TFPHashObjectList`
5. **Consolidate parsing** - all backends use `TfpgFontDefinition.ParseFontDesc`
6. **Complete IFontEngine** - remove all FFontRes legacy code

=== 2.3 New API Design

==== TfpgFontManager

[source,pascal]
----
unit fpg_fontmanager;

{$mode objfpc}{$H+}

interface

uses
  Classes, SysUtils, contnrs, fgl, fpg_base;

type
  TfpgFontManager = class(TObject)
  private
    FFontCache: TFPHashObjectList;  // Hash table for O(1) lookup
    FNamedFonts: TFPStringHashTable;  // Named font aliases: #Label1 -> Arial-12
    FDefaultFontDesc: string;
    FFixedFontDesc: string;

    function NormalizeFontDesc(const ADesc: string): string;
    function ResolveFontAlias(const ADesc: string): string;
  public
    constructor Create;
    destructor Destroy; override;

    // Main font API
    function GetFont(const ADesc: string): TfpgFontResource;
    procedure NotifyFontDestroyed(AFont: TfpgFontResource);

    // Named fonts (aliases like #Label1)
    procedure RegisterNamedFont(const AID: string; const ADesc: string);
    function GetNamedFontDesc(const AID: string): string;

    // Default fonts
    function GetDefaultFont: TfpgFontResource;
    function GetFixedFont: TfpgFontResource;

    property DefaultFontDesc: string read FDefaultFontDesc write FDefaultFontDesc;
    property FixedFontDesc: string read FFixedFontDesc write FFixedFontDesc;

    // Debugging and statistics
    function GetCacheSize: integer;
    function GetCacheStats: string;
    procedure DumpCache;
  end;

implementation

constructor TfpgFontManager.Create;
begin
  inherited Create;
  FFontCache := TFPHashObjectList.Create(True);  // Owns font resources
  FNamedFonts := TFPStringHashTable.Create;

  // Platform-specific defaults will be set by TfpgApplication
  FDefaultFontDesc := '';
  FFixedFontDesc := '';
end;

destructor TfpgFontManager.Destroy;
begin
  FFontCache.Free;
  FNamedFonts.Free;
  inherited Destroy;
end;

function TfpgFontManager.GetFont(const ADesc: string): TfpgFontResource;
var
  fdesc: string;
  descriptor: TfpgFontDefinition;
  normalizedKey: string;
begin
  if ADesc = '' then
  begin
    Result := GetDefaultFont;
    Exit;
  end;

  // Resolve named fonts (#Label1 -> Arial-12)
  fdesc := ResolveFontAlias(ADesc);

  // Parse and normalize descriptor for consistent cache keys
  descriptor := TfpgFontDefinition.Create(fdesc);
  try
    normalizedKey := descriptor.FontDesc;  // Uses normalized format

    // O(1) hash table lookup
    Result := TfpgFontResource(FFontCache.Find(normalizedKey));

    if not Assigned(Result) then
    begin
      // Create new platform-specific font resource
      Result := TfpgFontResource.Create(fdesc);

      if Result.HandleIsValid then
      begin
        Result.FFontDefinition := descriptor;
        descriptor := nil;  // Transfer ownership
        FFontCache.Add(normalizedKey, Result);
      end
      else
      begin
        // Font creation failed, return default font
        Result.Free;
        Result := GetDefaultFont;
      end;
    end;
  finally
    descriptor.Free;
  end;
end;

procedure TfpgFontManager.NotifyFontDestroyed(AFont: TfpgFontResource);
begin
  // Called by font destructor when ref count reaches 0
  if FFontCache.FindIndexOf(AFont) >= 0 then
    FFontCache.Remove(AFont);  // Remove from cache, will be freed
end;

function TfpgFontManager.ResolveFontAlias(const ADesc: string): string;
begin
  if (Length(ADesc) > 0) and (ADesc[1] = '#') then
  begin
    // Named font: #Label1
    Result := GetNamedFontDesc(Copy(ADesc, 2, Length(ADesc)));
  end
  else
    Result := ADesc;
end;

procedure TfpgFontManager.RegisterNamedFont(const AID: string; const ADesc: string);
begin
  FNamedFonts.Add(LowerCase(AID), ADesc);
end;

function TfpgFontManager.GetNamedFontDesc(const AID: string): string;
begin
  Result := FNamedFonts.Data[LowerCase(AID)];
  if Result = '' then
    Result := FDefaultFontDesc;  // Fallback
end;

function TfpgFontManager.GetDefaultFont: TfpgFontResource;
begin
  if FDefaultFontDesc = '' then
    FDefaultFontDesc := 'Liberation Sans-10';  // Fallback
  Result := GetFont(FDefaultFontDesc);
end;

function TfpgFontManager.GetFixedFont: TfpgFontResource;
begin
  if FFixedFontDesc = '' then
    FFixedFontDesc := 'Liberation Mono-10';  // Fallback
  Result := GetFont(FFixedFontDesc);
end;

function TfpgFontManager.GetCacheSize: integer;
begin
  Result := FFontCache.Count;
end;

function TfpgFontManager.GetCacheStats: string;
var
  i: integer;
  font: TfpgFontResource;
begin
  Result := Format('Font Cache: %d fonts cached'#13#10, [FFontCache.Count]);
  for i := 0 to FFontCache.Count - 1 do
  begin
    font := TfpgFontResource(FFontCache[i]);
    Result := Result + Format('  %s (RefCount: %d)'#13#10,
                              [font.FontDesc, font.RefCount]);
  end;
end;

procedure TfpgFontManager.DumpCache;
begin
  WriteLn(GetCacheStats);
end;

end.
----

// In fpg_main.pas

TfpgFontResource = class(TfpgFontResourceImpl)
protected
  FFontDesc: string;
  FFontDefinition: TfpgFontDefinition;
  FManager: TfpgFontManager;  // Weak reference, not owned
public
  constructor Create(const afontdesc: string);
  destructor Destroy; override;

  property FontDefinition: TfpgFontDefinition read FFontDefinition;

constructor TfpgFontResource.Create(const afontdesc: string);

  inherited Create(afontdesc);  // Platform-specific initialization
  FFontDesc := afontdesc;
  FFontDefinition := TfpgFontDefinition.Create(afontdesc);
  FManager := fpgApplication.FontManager;  // Weak reference

  // Notify manager that this font is being destroyed
  // Manager will remove it from cache if ref count is 0

    FManager.NotifyFontDestroyed(Self);

  FFontDefinition.Free;
  inherited Destroy;

==== Consolidated Font Descriptor Parsing

[source,pascal]
----
// Enhanced TfpgFontDefinition in fpg_base.pas

TfpgFontDefinition = class(TObject)
private
  FFontDesc: string;
  FFaceName: string;
  FSize: integer;
  FAttributes: TfpgFontAttributes;
  FAntiAliased: boolean;
  procedure ParseFontDesc;
public
  constructor Create(const AFontDesc: string);

  // Normalized descriptor for cache keys
  function GetNormalizedDesc: string;

  // Hash code for fast lookups
  function GetHashCode: Cardinal;

  property FontDesc: string read FFontDesc;
  property FaceName: string read FFaceName;
  property Size: integer read FSize;
  property Attributes: TfpgFontAttributes read FAttributes;
  property AntiAliased: boolean read FAntiAliased;
  property IsBold: boolean read GetIsBold;
  property IsItalic: boolean read GetIsItalic;
  property IsUnderline: boolean read GetIsUnderline;
end;

function TfpgFontDefinition.GetNormalizedDesc: string;
begin
  // Produce consistent descriptor for cache keys
  Result := FFaceName + '-' + IntToStr(FSize);
  if fpgFontBold in FAttributes then
    Result := Result + ':bold';
  if fpgFontItalic in FAttributes then
    Result := Result + ':italic';
  if fpgFontUnderline in FAttributes then
    Result := Result + ':underline';
  if not FAntiAliased then
    Result := Result + ':antialias=false';
end;

function TfpgFontDefinition.GetHashCode: Cardinal;
var
  s: string;
  c: char;
begin
  s := GetNormalizedDesc;
  Result := 0;
  for c in s do
    Result := ((Result shl 5) or (Result shr 27)) xor Ord(c);
end;

== 8. Conclusion

=== 8.1 Summary

The fpGUI font handling system suffers from unnecessary complexity due to:

1. **TfpgFont wrapper class** - adds no value, confuses ownership
2. **Incomplete refactoring** - old and new code paths coexist
3. **Manual reference counting** - error-prone, caused memory leaks
4. **No font manager** - logic scattered in TfpgApplication
5. **Inefficient cache** - O(n) linear search

While recent bug fixes have resolved critical memory leaks, the fundamental architecture needs simplification.

=== 8.2 Recommended Solution

**Phased Moderate Refactoring (Option C):**

* **Phase 1 (Week 1):** Create TfpgFontManager with hash-based caching
* **Phase 2 (Week 2):** Migrate widgets to use TfpgFontResource directly
* **Phase 3 (Week 3):** Remove TfpgFont wrapper, complete cleanup
* **Phase 4 (Ongoing):** Testing, documentation, verification

**Benefits:**

* Significantly simplified architecture
* Better performance (O(1) cache lookups)
