=== Canvas Interaction Model — Selection-Driven Mode

The canvas behaviour is driven by *what is selected in the object tree*, mirroring the
Haiku Icon-o-Matic approach.  Selecting a node type automatically arms the canvas with the
appropriate interaction mode — the user does not need to switch tools manually.

* Selecting a *shape* node → canvas enters shape-transform mode: a bounding box with
  handles is shown; drag to translate, rotate, scale, or shear.
* Selecting a *path* node → canvas enters path-edit mode: individual anchor points and
  Bezier handles are shown; drag to move nodes or adjust curve handles.
* Selecting a *style* node → canvas renders normally with no overlay; editing happens
  entirely in the style panel.

This replaces the current explicit Select / Node tool toggle for the primary workflow.
The remaining dedicated toolbar tools (Add Point, Delete Point, Pen, Rectangle, Ellipse,
Zoom, Pan) continue to exist as secondary tools that override the selection-driven mode
while active.

* [x] When the tree selection changes to a shape node, automatically switch the canvas to
  shape-transform mode (bounding box overlay, no path node editing).
* [x] When the tree selection changes to a path node, automatically switch the canvas to
  path-edit mode (anchor points and curve handles, no bounding box).
* [x] Node overlay scoped to selected path only; hit-testing restricted to that path.
* [ ] Keyboard shortcut: pressing Escape while a secondary tool is active returns to
  selection-driven mode without changing the tree selection.
* [ ] Retire (or repurpose) the explicit Select and Node toolbar buttons now that mode
  is driven by tree selection; keep Add Point, Delete Point, Pen, Rectangle, Ellipse,
  Zoom, Pan as secondary tools.

=== Shape Affine Transform — Bounding Box Interaction

HVIF shapes carry a full 6-element affine matrix (`Transform[sx, shy, shx, sy, tx, ty]`)
that encodes rotation, scale, shear, and translation in one step.  Currently Vertex
round-trips the matrix correctly but offers no way to inspect or edit it.  Raw matrix
editing is too low-level for typical users.

The bounding box is shown automatically whenever a shape node is selected in the object
tree (selection-driven mode — see section above).  This matches the Haiku Icon-o-Matic
and Inkscape model.

==== Canvas — Bounding Box Overlay

* [ ] When a shape node is selected, draw a dashed bounding box around its path geometry,
  accounting for the shape's current affine transform.
* [ ] Draw eight handles: one at each corner (rotation) and one at the mid-point of each
  edge (scale/shear).
* [ ] Plain drag anywhere inside the box — translates the shape (existing `HasTranslation`
  path, upgraded to full matrix when combined with other transforms).
* [ ] Corner handle drag — rotates the shape around its centre; cursor changes to a
  rotation arc on hover.
* [ ] Edge handle drag — scales the shape along the corresponding axis.
* [ ] Ctrl + edge handle drag — shears along that axis, matching Icon-o-Matic behaviour.
* [ ] Holding Shift during scale constrains to uniform scale.
* [ ] Live preview during drag: apply the in-progress matrix to the render without
  committing to the undo stack.
* [ ] On mouse-up, commit the final matrix via `TVertexCmdSetShapeTransform` (see below).
* [ ] Escape during drag cancels the operation and reverts the live preview.

==== Shape Properties Panel — Transform Read-Out

* [ ] Add a read-only "Transform" sub-section that becomes visible whenever `HasTransform`
  is True.  Display the decomposed values: rotation angle (degrees), X scale, Y scale,
  shear.  These are informational — editing is done on the canvas.
* [ ] When `HasTransform` is False (translation-only), the sub-section is hidden (or shows
  "No affine transform").
* [ ] "Reset transform" in the shape context menu must clear the full matrix back to
  identity (currently it only clears `HasTranslation`); update `ShapeMenuResetTransform`
  accordingly.
* [ ] "Freeze transformation" must bake the full affine matrix into path point coordinates,
  not just the translation; update `TVertexCmdFreezeTransform` accordingly.

==== New Undo Command

* [ ] `TVertexCmdSetShapeTransform` — stores old and new 6-element affine matrix for a
  shape; sets `HasTransform := True` (or False when matrix is identity); Description:
  `'Set shape transform'`.
