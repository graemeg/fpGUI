
                     fpGUI Toolkit

                   INSTALLATION NOTES



Building fpGUI from the Command Line (using PasBuild)
═════════════════════════════════════════════════════

fpGUI uses PasBuild, a Maven-inspired build tool for Free Pascal projects.
You will need PasBuild installed and the 'fpc' executable available in your
PATH. Your global fpc.cfg file should be set up correctly so the FPC compiler
can find the RTL and FCL units.

All commands are run from the project root directory.

To compile everything (framework, applications, examples, and tools):
   pasbuild compile -p unix
   pasbuild compile -p windows

To compile the framework only:

Under Linux and FreeBSD run:
   pasbuild compile -m fpgui-framework -p unix

Under Windows run:
   pasbuild compile -m fpgui-framework -p windows

Under MacOS run:
   pasbuild compile -m fpgui-framework -p macos

To compile with debug information, add the debug profile:
   pasbuild compile -m fpgui-framework -p unix,debug

To run unit tests:
   pasbuild test -m fpgui-framework -p unix,debug

All compiled units (*.o and *.ppu) are output to the
<fpgui>/framework/target/units/ directory.

Then in your own project, simply add "<fpgui>/framework/target/units" to
the -Fu unit path of your project.


Building fpGUI using Lazarus
════════════════════════════

Lazarus IDE uses Packages (.lpk files) to compile the required units and
keep track of compiled units and paths when creating applications. The
Lazarus package files are located in the "extras/" directory, separate from
the framework source code.

 * Start Lazarus
 * First, open the AggPas dependency package:
   Select Components->Open Package File (*.lpk) and open
     extras/aggpas/aggpas.lpk
   A new dialog will appear - click Compile.
 * Next, open the fpGUI toolkit package for your platform:
   Select Components->Open Package File (*.lpk) and open
     extras/lazarus_ide/<your platform>/fpgui_toolkit.lpk
   Under Linux/FreeBSD the .lpk file will be in the 'x11' directory.
   Under Windows the .lpk file will be in the 'gdi' directory.
   Under MacOS the .lpk file will be in the 'cocoa' directory.
   A new dialog will appear - click Compile.
 * Lazarus has now compiled the packages and will keep track of
   all the compiled units and paths.
 * Now lets open a project. Select Project->Open Project and select
   any project in the examples/gui directory. Select the *.lpi file.
 * Now select Run->Build and Lazarus will compile the project for
   you. The executable will be located in the same directory as the
   source. The compiled units will be placed in the <project>/units
   directory.

When you create your own project, all you need to do is tell Lazarus to
associate the 'fpgui_toolkit' package with your project and it will
automatically find all the fpGUI compiled units and source for you.

 * Creating a new project. Select Project->New Project.  Select
   Program and click the Create button.
 * Save the project in your preferred directory.
 * Associate fpGUI with your project. Select Project->Project Inspector.
   A new dialog will appear. Select Add then New Requirements. In the
   Package Name combobox, select the 'fpgui_toolkit' package and
   click OK.
 * You can now write your program and use any fpGUI units. Lazarus will
   automatically include the paths to the fpGUI compiled units for you.


Building fpGUI from the Free Pascal Text IDE
════════════════════════════════════════════

First you would need to setup the 'fp' IDE to find the related files.
As far as I understand the text mode IDE has its own built-in compiler
so doesn't read the standard fpc.cfg file.

 * Run the text mode IDE from the command line:  fp
 * Navigate the menus to: Options|Directories and select the 'Units'
   tab.
 * Now enter the following directories replacing the relevant parts with
   your actual full paths for fpGUI.

   For Unix-like systems (Linux, *BSD, OpenSolaris and MacOS):
   -----------------------------------------------------------
   full_path_to/fpGUI/framework/src/main/pascal/corelib
   full_path_to/fpGUI/framework/src/main/pascal/corelib/<platform>
   full_path_to/fpGUI/framework/src/main/pascal/corelib/render/software
   full_path_to/fpGUI/framework/src/main/pascal/gui
   full_path_to/fpGUI/framework/src/main/pascal/gui/db
   full_path_to/fpGUI/framework/src/main/pascal/3rdparty/regex

   For Windows:
   -----------
   full_path_to\fpGUI\framework\src\main\pascal\corelib
   full_path_to\fpGUI\framework\src\main\pascal\corelib\gdi
   full_path_to\fpGUI\framework\src\main\pascal\corelib\render\software
   full_path_to\fpGUI\framework\src\main\pascal\gui
   full_path_to\fpGUI\framework\src\main\pascal\gui\db
   full_path_to\fpGUI\framework\src\main\pascal\3rdparty\regex

 * Now select the 'Include files' tab and enter the following paths.
   Again change the paths to point to your actual directories and
   X11 or GDI corelib backend.

    For Unix-like systems (Linux, *BSD, OpenSolaris and MacOS):
    -----------------------------------------------------------
    full_path_to/fpGUI/framework/src/main/pascal/corelib
    full_path_to/fpGUI/framework/src/main/pascal/corelib/x11
    full_path_to/fpGUI/framework/src/main/pascal/corelib/render/software
    full_path_to/fpGUI/framework/src/main/resources

    For Windows:
    -----------
    full_path_to\fpGUI\framework\src\main\pascal\corelib
    full_path_to\fpGUI\framework\src\main\pascal\corelib\gdi
    full_path_to\fpGUI\framework\src\main\pascal\corelib\render\software
    full_path_to\fpGUI\framework\src\main\resources

 * Now changes to 'Miscellaneous' tab, PPU output directory. Type in
   the edit box:  full_path_to/fpGUI/framework/target/units

   NOTE:
   This will place all the compiled *.ppu and *.o files into the
   framework/target/units/ directory. Make sure the directory exists
   before you try to compile for the first time. FPC doesn't create
   directories for you!

 * To create all the units for fpGUI,
   compile one of the following:
     full_path_to/fpGUI/extras/lazarus_ide/x11/fpgui_toolkit.pas   // for Unix-like systems
     full_path_to\fpGUI\extras\lazarus_ide\gdi\fpgui_toolkit.pas   // for Windows

 * Now you can restore your Free Pascal configuration by:
     - remove all the directories added in the Units Tab
     - remove the directories added in Include Files Tab
     - remove units from the Miscellaneous tab

 * Add the compiled units directory to the Units tab:
     full_path_to/fpGUI/framework/target/units

You are ready to open your project's main program unit (F3) and
compiling it by pressing (F9).


Compiling any of the examples from the Command Line
═══════════════════════════════════════════════════

You need to compile fpGUI first, as mentioned above!
All examples are compiled using PasBuild from the project root directory.

To compile all examples at once:
   pasbuild compile -m fpgui-examples -p unix

To compile a specific example:
   pasbuild compile -m examples-gui-lmmig -p unix
